### Lingkungan & Konfigurasi Uji
1. **Basis Data**: Supabase PostgreSQL dengan skema relasional terisolasi, Row Level Security (RLS), Column-Level Grants, fungsi bisnis atomik (`SECURITY DEFINER` dengan `SET search_path = public, pg_temp`), serta trigger guard.
2. **Backend & API**: Next.js App Router (Server Actions & Route Handlers), validasi skema Zod di runtime, dan Supabase Auth SSR.
3. **Frontend**: Antarmuka web enterprise padat berbasis React & Tailwind CSS, format mata uang `Intl.NumberFormat('id-ID')`, dan zona waktu bisnis `Asia/Jakarta` (`(now() AT TIME ZONE 'Asia/Jakarta')::date`).
4. **Alat Otomasi**: Vitest 3.x (Unit & Integration), Playwright 1.50+ (End-to-End Browser), psql / SQL Automated Test Scripts, dan PowerShell Concurrency Load Runner.
